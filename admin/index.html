Edit. Save. Share.

Change a field and click Save in Pages CMS. Saving publishes your content through GitHub Pages, usually within a few minutes. Reload your website to see it. Your public links stay the same.

Plain-text fields accept ordinary text and line breaks; you do not need HTML. A link field expects a full https:// address. Save only information you intend to make public.

GitHub keeps previous versions of your changes. Drafts that you have not saved in the editor are not published.
